# 변경 이력

## [2026-09-26] 두 번째

### 수정
- **전체 소등 해제가 동작하지 않던 문제** — 이 브로드캐스트(`0x09`)는 프로토콜상
  ACK도 응답도 없어서(실측에서 응답한 장치가 하나도 없음) 애드온이 보낸 소등을
  스스로 알 수 없었다. 그래서 HA 스위치가 계속 off로 남고, 누를 때마다 매번
  소등(`0x65`)만 전송되어 해제(`0x66`)는 나가지 않았다.
  - 이 경우에만 전송 직후 상태를 낙관적으로 발행한다 (확인할 프레임이 없음)
  - 소등·해제 직후 조명 상태를 다시 조회한다. 월패드도 브로드캐스트 뒤에 방별
    조회를 돌린다(실측). 그러지 않으면 다음 폴링까지 최대 5분간 어긋난다.
- **온도조절기 외출 모드가 반대로 동작하던 문제** — HA climate은 preset 이름
  (`away`/`none`)을 보내는데 `on`만 켜기로 인식해 외출을 켜면 해제가 전송됐다.
- **외출모드 상태가 HA 조작 시 갱신되지 않던 문제** — 애드온이 보낸 프레임은
  버스에서 되돌아오지 않지만 `0x60`이 `0x0D` ACK를 보낸다. 이 ACK를 실제 확인
  으로 받아들이도록 했다.

## [2026-09-26]

5.4시간(6,492패킷) RS485 실측 분석 결과를 반영. 분석 문서는
`kocom-wallpad-rs485-test-tool/protocol.md` 참고.

### 수정 (잘못된 상태 보고)
- **동작감지기 `cmd 0x00`을 '감지 없음'으로 읽던 오류** — 실제로는 경비(외출모드)
  설정이다. 외출모드 진입을 '동작 없음'으로 잘못 보고하던 문제가 해소된다.
- **명령 프레임과 ACK를 상태로 반영하던 문제** — 이제 장치가 스스로 보낸 `0x0B`
  보고만 상태로 신뢰한다. HA 상태가 실제 장치 동작을 뒤따른다.
  - 가스밸브: 명령 직후가 아니라 약 2.9초 뒤 완료 보고 시점에 상태가 바뀐다
  - 콘센트: 장치가 거부한 채널(예: 주방 상시 전원)이 켜진 채로 정확히 표시된다
- **엘리베이터 호출/도착 판정** — 커맨드가 아니라 `payload[0]`으로 구분한다
  (`0x00` 호출 / `0x03` 도착). 도착을 호출로 오독하던 문제가 해소된다.

### 추가
- **전체 소등** 스위치 — 현관 일괄 소등과 같은 브로드캐스트(`0x09`) 프레임.
  해제하면 장치가 소등 직전 상태를 스스로 복원한다.
- **외출모드** 스위치 — 가스 차단 → 보조 차단 → 경비 활성 → 전체 소등 순서의
  연쇄 매크로. 해제 시 가스는 다시 열지 않는다.
  - `away_call_elevator` 옵션으로 엘리베이터 호출 포함 여부 선택 (현관 스위치 방식)
  - `away_gas_room` 옵션으로 차단할 가스밸브 방 지정
- **온도조절기 외출 모드** (preset `away`) — 켜면 장치가 설정온도를 10°C로
  스스로 바꾸고 끄면 되돌린다. 애드온은 이를 정상 동작으로 처리한다.
- **월패드 시각 센서 2종** — 월패드가 보내는 시각과 시스템 시각의 오차.
  버스가 살아 있음을 보여주는 가장 좋은 지표다.
- **진단 엔티티 6종** — 월패드 통신·RS485 연결 상태, 마지막 수신 경과,
  송수신 패킷 수, 프레임 오류율.
- **MQTT 가용성(LWT)** — 애드온이 죽으면 브로커가 offline을 발행해 HA에서
  모든 엔티티가 unavailable로 바뀐다.
- 방 전체 켜기/끄기 — `kocom/{room}/light/all/command`. 8바이트 와일드카드
  한 프레임으로 처리하며, 장치 응답으로 실제 채널 수를 알 수 있다.
- 장치 코드 `0x2D`(보조 차단), `0x86`(시각동기) 인식
- 커맨드 `0x3B`/`0x3C`(시각 전달/요청), `0x66`(전체 소등 해제) 인식
- 패킷 타입 `0x09`(브로드캐스트) 및 byte3 하위 니블(재시도 시퀀스) 해석

### 변경
- 환기장치 프리셋에서 `air purification` 제거 — 실측에서 관측되지 않았다.
- 엘리베이터 층수 센서 제거 — 층 정보 바이트가 항상 `00`이었다.
  (층을 보고하는 세대는 상태 JSON의 `floor` 키로 템플릿 센서를 만들 수 있다.)
- 같은 값의 중복 발행 억제 — 월패드는 응답 없는 프레임을 3회까지 재전송한다.
